# Al-Ahruf Al-Muqaththaah Analysis

## Why This Project?

Unlike common beginner datasets (Titanic, Netflix, Sales, etc.), this project transforms an Islamic studies research publication into a structured data analytics project.

It demonstrates how data analytics techniques can be applied to Qur'anic studies.

## Background

This project explores the distribution and interpretation of Al-Ahruf Al-Muqaththaah in the Qur'an using Python, SQL, and data visualization.

The dataset was manually constructed based on my published research about Tafsir Al-Ibriz by K.H. Bisri Musthofa.

---

## Objective

- Analyze Muqaththaah patterns
- Explore revelation period
- Explore interpretation categories
- Visualize the dataset
